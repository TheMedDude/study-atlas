# Pharmacology Memorize: source-grounded proposal

Status: **ideas and blueprint**, not a released content bank. The user requested inspection of Microbiology Memorize and suitable Pharmacology ideas. The first 1.3 implementation is design/device work; no unreviewed synthesis was added.

## Existing Microbiology patterns

The room contains 40 organism dossiers, three classification trees, five matrices and six heuristic records. Dossiers collect literal page-linked facts and launch related MCQs; classification offers a tree/simulator; matrices hide/reveal values; heuristics include refs.

Reuse precise source access, linked practice, connected facts and adjacent comparisons. Avoid treating every course as an organism catalog, desktop panels on phones, uncited matrix cells, universal shortcuts beyond the source, or reporting reveals as recall. The scientific synthesis was not independently revalidated in this interface task.

## Recommended Pharmacology tools

| Tool | Chapter | Study task | Interaction/evidence boundary |
| --- | --- | --- | --- |
| Routes comparison | Introduction & ROA | Route properties, constraints and first-pass relationships in the source | Filtered comparison with cell-level source refs; unscored hiding; linked reviewed MCQs. |

| PK relationships sheet | Pharmacokinetics | Equations, units and necessary conditions | Always show condition with formula; link validated calculations, don't invent clinical doses. |
| Dose-response comparisons | Pharmacodynamics | Potency/efficacy and agonist/antagonist curve changes | Source graph crops retain axes/conditions; linked practice. |
| Receptor-to-response map | ANS/Adrenergic Drugs | Receptor, signaling/tissue effects and drug distinctions | Filter by receptor; retain tissue/dose/context; source-backed edges only. |
| Adrenergic drug directory | ANS/Adrenergic Drugs | Selectivity, mechanisms, uses and adverse effects | Compact detail and targeted practice; don't promote introductory illustrative drugs into memorization lists. |

Start with route/PD comparisons and an ANS receptor map: clear study tasks using indexed concepts. Expand after touch interaction and source QA.

## Required content contract

Stable ID, title, chapter, concept IDs, exact refs for each factual cell/node/edge, uncertainty exclusions, revision, reviewer identity and review status. Link activities by concept IDs, not fuzzy names. Record/review any inference explicitly. Never fill a blank from outside drug references.

Existing Microbiology synthesis schemas are incumbent implementation, not sufficient validation standards for new content. Use subject-neutral entities/comparisons/processes behind an adapter instead of putting drugs in organisms. Preserve current paths/data.

## Device behavior

Phone: choose a tool then a comparison/process/entity; visible Back action. Tablet: list/detail only while both readable. Dense matrices scroll locally with row/column context and visible affordance. Every fact opens its exact source. Color never carries meaning alone. Browsing/revealing never creates history; completed validated activities do.

## Acceptance

Faithful extraction -> page-linked candidates -> independent review -> schema/provenance -> layout/keyboard/synthesized touch -> actual deployment verification. Missing or unresolved relationships stay absent or explicitly deferred.
