# Bundled typefaces

These unmodified open-source font files are served from this repository. The app makes no Google Fonts/CDN request at runtime. The accompanying SIL Open Font License files apply to each font.

- **Inter 4.1 variable, upright** — [official font file](https://rsms.me/inter/font-files/InterVariable.woff2?v=4.1), [project](https://rsms.me/inter/), [license source](https://github.com/rsms/inter/blob/v4.1/LICENSE.txt). English UI, headings, questions, answers and Latin technical terms.
- **Noto Sans Arabic variable, upright** — [Google Fonts font file](https://github.com/google/fonts/blob/main/ofl/notosansarabic/NotoSansArabic%5Bwdth%2Cwght%5D.ttf), [family](https://fonts.google.com/noto/specimen/Noto+Sans+Arabic), [license source](https://github.com/google/fonts/blob/main/ofl/notosansarabic/OFL.txt). Arabic script; Latin terms fall back to Inter through the font-face Unicode range.

Downloaded 2026-11-05. Typography direction also informed by [Duolingo's published hierarchy and body-text guidance](https://design.duolingo.com/identity/typography), [Khan Academy's sans-serif design guidance](https://www.khanacademy.org/computing/computer-programming/html-css/html-css-further-learning/a/webpage-design), and [AMBOSS's documented question interface](https://support.amboss.com/hc/en-us/articles/360036038991-Using-Study-Mode-Exam-Mode). Study Atlas uses its own typefaces and retains its existing palette.
